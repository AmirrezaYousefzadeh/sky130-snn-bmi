# Event-driven spiking BMI decoder on the open SkyWater 130 nm PDK

Reproducible reference implementation for the paper *"Can an open 130 nm node decode the brain at
microwatts?"* (in preparation for the IOP *Neuromorphic Computing and Engineering* focus collection on
neuromorphic brain-machine interfaces). Everything needed to regenerate every number of the paper is here:
data preparation, quantisation-exact training, bit-exact RTL for six core variants, OpenLane hardening,
gate-level simulation (functional and SDF) and per-pin OpenSTA power.

Pipeline: NeuroBench primate-reaching data → quantisation-exact SNN training → bit-exact RTL →
OpenLane hardening → gate-level simulation of the real spike stream → OpenSTA per-pin activity power.

## Layout

| Path | Contents |
|------|----------|
| `sw/prepare_data.py` | NeuroBench-identical preprocessing (4 ms bins, binary per channel, 50/25/25 segment split) |
| `sw/snn_int.py` | Integer reference model = the arithmetic of the RTL; memory image export; NeuroBench R² |
| `sw/train_snn.py` | Surrogate-gradient training whose forward pass is bit-exact with the integer model |
| `sw/eval_int.py`, `sw/export_vectors.py`, `sw/export_firmware.py` | Full-test evaluation, testbench vectors, C header for the RISC-V baseline |
| `rtl/bmi_snn_top.v`, `rtl/clk_gate_hd.v` | Sequential event-driven / dense-mode core with one SRAM22 weight macro, integrated clock gate, 50 MHz |
| `rtl/bmi_snn_par.v` → `rtl/gen/bmi_snn_{scmem,lmem,lmin,lmem2,lmin2,hw,min,ming,m12,sp,sp8,min32,min16}.v` (via `sw/gen_variant.py`) | Parallel SRAM-free core (one event per cycle, two-stage row pipeline): weights in a flip-flop register file, in a latch memory (`LATCH_MEM`: one clock gate per row, gate one cycle ahead of the data) or hardwired (`sw/gen_weights_rom.py`, optionally pruned); `GATE_DP` clocks the weight-row register and the membrane bank only when written; `W2_PIPE` pipelines the per-spike W2 read and add (needed by the latch memories at the slow corner); 20/16/12-bit state, no-dense, H=32/16 variants, generated as flat modules |
| `firmware/bmi_snn_sw_tuned.c` | Hand-tuned software baseline (unclamped 32-bit adds with a per-bin range check, unrolled row loop); built with `FW_SRC`/`FW_OPT`, run with `VARIANT=_tuned ./sim/run_riscv.sh gls --vcd` |
| `rtl/gen/bmi_snn_topg.v` | The sequential SRAM core with `GATE_MEM`: 16 membrane groups (one weight word each) on their own clock gates |
| `sim/measure_design.sh <design> func\|sdf` | Complete energy measurement set of a variant (functional or SDF gate-level, full-depth dump, per-pin OpenSTA) |
| `sw/collect_designs.py` | PPA/energy table of all variants → `results/DESIGNS.md`, `paper/designs_table.tex`, `paper/numbers2.tex`, `paper/figures/variants.pdf` |
| `sim/tb_bmi_snn.v`, `sim/run_rtl.sh`, `sim/run_gls.sh` | Bit-exact testbench, RTL and gate-level simulation (functional or SDF; VCD for power) |
| `firmware/`, `sim/run_riscv.sh` | Same algorithm in C for the open VexRiscv SoC of `sky130-vex2-soc` |
| `synthesis/bmi_snn_top/config.yaml`, `synthesis/run_synthesis.sh` | OpenLane 2 configuration (sky130_fd_sc_hd, 25 ns clock, SRAM22 macro, custom PDN) |
| `power/run_vcd_power.sh` | Per-pin OpenSTA power from a full-depth gate-level VCD (headline method) |
| `power/run_avg_power.sh`, `power/run_time_power.sh` | Reference-flow OpenSTA power (global median activity, awake/idle case analysis), windowed timeline |
| `results/` | Trained models (`model_int.npz`, `train.json`, `eval_int.json`), collected numbers and figures |
| `paper/` | LaTeX source of the manuscript |

## Requirements

* sky130A PDK (volare, `sky130A`), OpenLane 2.3.10 (Nix flake), OSS CAD Suite (Icarus Verilog 13, Yosys 0.44),
  OpenSTA 2.6 (inside the OpenLane Nix shell) — install as in
  [`sky130-vex2-soc/setup`](https://github.com/AmirrezaYousefzadeh/sky130-vex2-soc). This repository expects
  that repository checked out next to it as `../skywater` (SRAM22 macro views under
  `synthesis/sky130_vex2_soc/macros/`, the VexRiscv SoC netlist for the software baseline, the RISC-V toolchain
  and the reference power scripts); `synthesis/bmi_snn_top/macros` is a symlink to it. Paths to `/media/pdk` and
  `/media/hardware_design_tools` are set at the top of the scripts and can be overridden with `PDK_ROOT` /
  `OPENLANE_ROOT` / `HARDWARE_TOOLS_ROOT`.
* Trained integer weights are regenerated by step 2 below in about five minutes per session on a GPU
  (`results/models/*/train.json` and `eval_int.json` are kept; the `.npz` weight files are not tracked because the
  hardwired ROM files `rtl/weights_rom.vh`, `rtl/h32/`, `rtl/h16/` and the testbench vectors derive from them).
* Python 3.12 with torch (CUDA optional), numpy, scipy, h5py, scikit-learn: `python3 -m venv .venv && .venv/bin/pip install torch numpy scipy h5py scikit-learn`

## Measurement recipe (for comparable future work)

* **Task**: NeuroBench primate reaching, streaming (4 ms bins, binary channel indicators, no spike sorting),
  sessions `indy_20160622_01`, `indy_20160630_01`, `indy_20170131_02`, NeuroBench 50/25/25 segment split.
* **Accuracy threshold**: mean test R² over the three sessions ≥ 0.55 (these models: 0.583 for H = 64, 0.572 for H = 32, 0.555 for H = 16).
* **Metric**: energy per 4 ms bin at real-time throughput (output valid before the next bin ends), from the
  post-route netlist + SPEF, gate-level activity of the real test stream (SDF where tractable), per-pin OpenSTA
  power at the typical corner; report average power at 250 bins/s for the declared idle strategy, idle power,
  leakage, latency, area and the accuracy of the submitted netlist.
* **Openness**: RTL, weights, flow configuration and raw reports released so that any number can be regenerated.
